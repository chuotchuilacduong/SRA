TROUBLESHOOTING:

  Problem: "Killed: 9" (Out of Memory)
  Solution: Reduce memory usage
    bash run_retrieve_linearrag_test_all.sh     # Use test mode
    OR
    BATCH_SIZE=8 MAX_WORKERS=1 bash run_retrieve_linearrag_test_all.sh

  Problem: "spacy" module not found
  Solution: Install spacy model
    python -m spacy download en_core_web_sm
    pip install spacy

  Problem: File not found (corpus.json)
  Solution: Download SRA-Bench dataset
    python - <<'PY'
    from huggingface_hub import snapshot_download
    snapshot_download(
        repo_id="WeihangSu/SRA-Bench",
        repo_type="dataset",
        local_dir="data/bench",
    )
    PY

  Problem: "sragents: command not found"
  Solution: Install package
    pip install -e .

RECOMMENDED WORKFLOW:

  1. Setup Environment:
     conda activate linearag311
     cd /path/to/SRA

  2. Test on small subset first:
     bash run_retrieve_linearrag_test_all.sh

  3. If successful, run full benchmark:
     bash run_retrieve_linearrag_all.sh

  4. Check results:
     ls -lh results/retrieval/*linearrag.json
     python - <<'PY'
     import json
     for dataset in ['theoremqa', 'champ', 'logicbench']:
       data = json.load(open(f"results/retrieval/{dataset}-linearrag.json"))
       metrics = data['metrics']
       print(f"{dataset}: Recall@50={metrics.get('Recall@50', 'N/A'):.4f}")
     PY
